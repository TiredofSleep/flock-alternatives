# Ceremony script (draft)

`script.json` is the step list for the key ceremony in `design/ceremony-protocol.md`: 13 steps (S00–S12),
each with the line the Ceremony Administrator reads aloud, what the Internal Witness confirms, and when
to stop. Nothing secret is ever read aloud: only steps, bag serials, hashes and public fingerprints.

It works today as a paper checklist. The tooling that would render it, track bag serials, build the
before and after publication packages, and compare transcripts (task 10 in `HANDOFF-UPDATE-2.md`) is
not built yet.

**Draft:** pending the outside auditor's sign-off and an independent security review.
